# AI Gateway Pro

Premium AI Router Gateway Pro — Vercel/Linear 2026 Style

## Features
- Real-time dashboard (Vercel/Linear 2026 UI)
- Global Proxy Search + Combo Pool
- Auto Import Proxy
- Delete Guard with 409 toast
- 18+ Provider Support
- Real-time request logs & audit

## Quick Start

### Backend (Node.js)
```bash
cd server
npm install
npm run dev
# or
node server.js
```

### Frontend (Vite)
```bash
cd app
npm install
npm run dev
```

## API Endpoints
- `GET /api/gateway/state`
- `GET /api/gateway/proxies/search`
- `POST /api/gateway/proxies/import`
- `GET /health`

## Deploy
- Frontend: Vercel
- Backend: Railway / Render / VPS
